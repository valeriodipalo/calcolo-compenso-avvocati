## Calculator Specification

Based on Andreani's feature set (the only fully-featured competitor), our calculator must include:

### Inputs
1. **Durata pena** — years / months / days (3 fields)
2. **Data inizio detenzione** — date picker
3. **Liberazione anticipata** — toggle ON/OFF (calculation facoltativa)
4. **Liberazione anticipata speciale** — toggle 45/75 giorni (only relevant for periods within D.L. 146/2013 window: 2010-01-01 to 2015-12-23, but UI keeps the toggle for completeness)
5. **Solo semestri completi** — toggle (if ON, interruzioni reset the semester; if OFF, fractions sum up to 6 months)
6. **Calcola fino al** — optional end date (if empty: fine pena virtuale)
7. **Periodi già scontati** — multiple ranges (presofferto, custodia cautelare, domiciliari, affidamento)
8. **Interruzioni della pena** — multiple ranges (gravi motivi salute, ricovero psichiatrico, sospensione, etc.)

### Outputs
1. **Data fine pena nominale** (without LA detraction)
2. **Data fine pena con LA** (with detraction)
3. **Fine pena virtuale** (if no end date specified)
4. **Giorni totali di detrazione**
5. **Numero di semestri utili** maturati
6. **Tabella periodi**: per ogni semestre — data inizio, data fine, giorni LA, status
7. **Pena residua effettiva** (al netto di scontati)

### Differentiators vs Andreani
- Native React component (not iframe)
- Inline result table (Andreani only shows final date)
- Worked example button: "Esempio: pena 3 anni con detenzione dal 2024-01-01"
- Copy-to-clipboard for result summary
