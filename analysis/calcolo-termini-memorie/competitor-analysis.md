## Tool Specification (Calculator)

The calculator must handle 5 distinct scenarios with a single UX flow:

**Step 1**: User inputs the procedure-start date (or selects "regime")
- If start date < 28/02/2023 → vecchio rito (183/190)
- If start date ≥ 28/02/2023 → Cartabia (171-ter/189/275-bis)

**Step 2**: User selects scenario
- **Vecchio rito**:
  - (A) Memorie 183 c. 6 — input: data udienza (dies a quo) → output: 3 scadenze (+30, +60, +80)
  - (B) Comparse 190 — input: data rimessione → output: 2 scadenze (+60, +80)
- **Cartabia**:
  - (C) Memorie integrative 171-ter — input: data udienza ex art. 183 → output: 3 scadenze a ritroso (-40, -20, -10)
  - (D) Note pc + comparse + repliche 189 (trattazione scritta) — input: data udienza collegiale → output: 3 scadenze a ritroso (-60, -30, -15)
  - (E) Note + comparse 275-bis (discussione orale) — input: data udienza collegiale → output: 2 scadenze a ritroso (-30, -15)

**Step 3**: Options
- Toggle sospensione feriale (default ON)
- Mode "prudenziale" vs "Cassazione 13201/2006" (for termini plurimi)
- Customizable festività italiane (default: include national + San Francesco from L. 151/2025)

**Step 4**: Output
- Table with each scadenza: data, giorno settimana, eventuali shift (sabato/festivo)
- "Add to Google Calendar" or "Copy" button (optional, post-MVP)
- Explanation of which articles apply
